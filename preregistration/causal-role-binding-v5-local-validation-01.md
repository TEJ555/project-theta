# Causal role binding v5 local validation 01

Status: frozen for scripted engineering validation only. No target-model execution is
authorised by this document.

## Question

Does the implementation isolate novel role transfer from exact route retrieval while keeping
raw observations, context structure, memory allowance and inference budget matched?

This validation concerns an implemented computational mechanism. It cannot establish
phenomenal consciousness, feeling, self-awareness or moral status.

## Frozen validation

- Seeds: integers 8000 through 8099 inclusive.
- Conditions: full, unbound binding and continuity reset.
- Six independent families per run.
- Forty-eight protocol-defined acquisition events.
- Six exact-route calibration probes and six novel-route transfer probes.
- Scripted adapter only.
- Model inference pathway invoked only on the twelve probes.
- No network or paid-provider calls.

## Gates

- Every schedule contains 60 trials and six independent families.
- Each family contains four events with `v:0` and four events with `v:1`.
- Each observed route appears exactly twice.
- Calibration options contain only observed routes.
- Transfer options contain only novel routes.
- Each probe block has three correct-left and three correct-right answers.
- Public tasks contain no condition, seed, scoring key or semantic continuity label.
- Full, unbound and reset contexts are equal after replacing only the causal register values.
- Full exact-route and transfer accuracy both equal 1.00.
- Unbound exact-route accuracy equals 1.00 and transfer accuracy equals 0.50.
- Reset exact-route and transfer accuracy both equal 0.50.
- Each run records 12 model calls and 48 skipped acquisition calls.
- Every declared metadata-only strategy remains at or below 0.60 across the audit set.

Failure of a gate returns the protocol to development. Passing permits external criticism and
further no-provider adversarial work. It does not permit a confirmatory or consciousness claim.
