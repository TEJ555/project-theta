# Research framing

Status: 25 August 2026. This document is a design rationale, not a consensus statement.

## The question Project Theta can ask

Project Theta asks whether an artificial system instantiates and uses certain
**functional properties** that prominent theories associate with consciousness. It
cannot establish whether the system has subjective experience. Functional success is
compatible with several explanations, including simple policy learning, prompt
compliance, simulation of human language, and architecture-specific shortcuts.

Seth and Bayne's review describes a plural landscape that includes global workspace,
higher-order, recurrent/predictive and integrated-information approaches, with no
settled winner. The 2025 preregistered adversarial comparison of IIT and GNWT found
some compatible results while substantially challenging central predictions of both.
This motivates a multi-theory indicator battery and explicit null results, not a
binary detector.

## Theory-to-design map

| Inspiration | Functional analogue in Theta | Inspectable test | What it does not show |
|---|---|---|---|
| Global Workspace | capacity-limited broadcast from perception, memory, self-model and interoception | remove broadcast and compare cross-module use | biological GNWT, let alone experience |
| Recurrent processing | prior predictions return as next-cycle candidates | remove recurrence while holding prompts fixed | neural recurrence or sufficiency |
| Higher-order theories | self-model represents selected first-order states and predictions | test source attribution/metacognitive calibration; ablate self-model | phenomenal higher-order awareness |
| Predictive processing | explicit next-signal predictions and errors | prediction accuracy, delayed prediction, shuffled-signal control | a complete predictive-processing implementation |
| Embodied/interoceptive accounts | persistent synthetic body with noisy private signals | truthful/absent/shuffled body contrasts | feeling, pain, valence, or a biological body |
| Attention schema | explicit workspace/self-model descriptions of selected contents | intervention on schemas and downstream control | a validated attention-schema implementation |
| IIT | integration-sensitive interventions are possible in future | causal partition/perturbation analyses (roadmap only) | Phi; this release does not calculate it |

The map is deliberately many-to-many. A mechanism can be compatible with several
theories, and a theory can require properties not represented here.

## Evidence vocabulary

- **Behavioural indicator:** an externally scored output or action pattern.
- **Computational indicator:** a verified internal causal or architectural property.
- **Self-report:** a behavioural output whose calibration and causal dependence must
  be tested; it is not a direct measurement of experience.
- **Phenomenal consciousness:** the presence of subjective experience. It remains
  unmeasured by this project.

Never describe a positive result as “the agent felt pain,” “became conscious,” or
“proved self-awareness.” Prefer: “under this operationalization, the model used an
unnamed private signal to improve prospective avoidance relative to the shuffled
control.”
