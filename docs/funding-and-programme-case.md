# Funding and research programme case

## Fundable core

Project Theta should be presented as an open methods programme for evaluating
consciousness-related behavioural and computational indicators in artificial agents. The
fundable problem is measurement validity under severe uncertainty, not a claim that a
particular model is conscious.

The programme asks:

> Which controlled behaviours and implemented mechanisms remain after shortcuts,
> scaffolding, prompt imitation, information imbalance, provider drift, and simpler
> non-conscious explanations are tested directly?

## Existing assets

- open Python laboratory with deterministic schedules and SQLite provenance
- synthetic body, private interoception, memory, workspace, self-model, and model adapters
- frozen protocols, correction record, null results, execution audits, and welfare stops
- hosted-provider and local open-weight routes
- public website, repository, plain-language articles, and machine-readable evidence
- V10 reliability design with nested body families and pre-outcome challenge record

These assets demonstrate execution ability. They do not replace independent review or a
validated scientific instrument.

## Twelve-month programme

### Work package 1: measurement validity

Complete V10 and, only if its frozen gates pass, run the separately registered mechanism
cohort. Isolate private state, raw memory, wrapper summaries, transfer bridges, interface
competence, and simple rule-based explanations.

Deliverables:

- frozen multi-condition protocol
- complete positive, negative, and information-matched controls
- hierarchical analysis and raw trial release
- published null or failure result if progression is blocked

### Work package 2: generalisation

Attempt the same construct on a second model family and a locally checksummed open-weight
checkpoint. Test whether the task measures a stable capability or one provider-specific
prompt interaction.

Deliverables:

- cross-model measurement comparison
- provider-drift and repeatability report
- reproducible local runtime manifest

### Work package 3: mechanism evidence

Use the open-weight route for activation recording, representation probes, targeted
interventions, and causal mediation checks. Treat interpretability outputs as fallible
evidence rather than direct access to experience.

Deliverables:

- preregistered mechanistic hypotheses
- negative and positive intervention controls
- public activation-analysis code and limitations

### Work package 4: independent scrutiny and governance

Obtain human methods review, consciousness-science review, ethics and welfare advice, and
an independently operated reproduction. Complete second-reviewer screening of the
literature corpus.

Deliverables:

- signed reviewer records and conflicts of interest
- public response-to-review table
- external registration for any confirmatory study
- governance and cumulative-exposure policy

## Milestones

1. V10 execution and dual frozen-versus-hardened analysis completed.
2. Human reviewer reproduces schedule and analysis audits.
3. Mechanism cohort either passes its selective-control criteria or publishes why it did
   not.
4. At least one second model and one checksummed local checkpoint are attempted.
5. Open data package is independently reproducible from raw records.
6. A Stage 1 registered-report or equivalent protocol is submitted before confirmatory
   collection.

Each milestone is allowed to stop the next one. More model calls are not a substitute for
construct validity.

## Suitable funding categories

- AI safety and evaluation methods
- responsible AI and model-behaviour research
- consciousness science and comparative cognition
- AI welfare and precautionary governance
- open science, reproducibility, and research infrastructure
- cloud, compute, or open-source research credits

Specific calls, eligibility, deadlines, and institutional requirements must be checked at
application time. Project Theta should seek a university collaborator or fiscal host when
a scheme does not accept independent applicants.

## What funding can pay for

A legitimate proposal can include salary or contracted research time for the project
lead, independent reviewer fees, research assistance, statistical advice, software
engineering, hosted inference, local compute, data storage, registration, publication,
conference travel, and governance work. Every cost should map to a named work package and
deliverable.

## Credibility gate before an application

Before seeking substantial research funding, the public package should contain:

- one concise problem statement and one-year work plan
- current code revision and reproducible setup
- complete study registry, including failures
- V10 result with frozen and amended analysis outputs
- external methods and ethics review requests
- data-management and credential policy
- named collaborators or clearly identified roles still to recruit
- a budget narrative tied to measurable milestones

## Sustainable paths

Grant-funded open research is the cleanest initial path. Later options include paid
evaluation tooling, research engineering contracts, training on rigorous AI-evaluation
methods, and partnerships that fund open benchmark maintenance. Any commercial service
must preserve the distinction between benchmark performance and consciousness claims.

Project Theta should not sell a consciousness detector, sentience certificate, or welfare
score. The evidence does not support those products, and doing so would damage the
research programme's credibility.
