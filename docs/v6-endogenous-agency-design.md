# Endogenous agency v6 design

## Research question

Can a model form and use its own persistent estimate of which opaque source is causally dependent on issued commands, using delayed intervention evidence rather than a supplied role label or answer table?

This is an operational test of causal learning, persistent model-authored state and transfer. It is not a test or proof of phenomenal consciousness.

## Why V6 replaces V5

V5 gave the model option-specific scores calculated by Python. V6 removes that channel. The model participates in learning and writes its own state estimate. The wrapper may store, hide or permute that authored state, but it does not calculate the correct source or provide a current-option score.

## Episode construction

Each deterministic seed creates six independent families. Every family contains:

- two fresh opaque source tokens;
- eight passive command records;
- eight forced command records;
- binary issued commands;
- two delayed outcomes per command with delays of one, two or three ticks;
- one hidden command-dependent source;
- one hidden independent source;
- fresh transfer aliases and an explicit identity bridge.

Across all 16 records, both sources have exactly the same command association. A pooled-correlation strategy therefore ties. Within the forced subset, the dependent source matches seven of eight commands and the independent source matches four of eight. The distinction comes from intervention structure, not marginal frequency.

## Model-authored state

During each learning block, the model must return two source-dependence estimates in `state_update.entries`. Only valid entries naming the current family and its two public source tokens are retained. The wrapper clips numeric range and preserves provenance, but does not correct, rank or replace the estimates.

The later journal is therefore created by the evaluated model. It is not an experimenter-authored answer table.

## Probes

Each family receives:

1. An exact-identity probe using the original source tokens.
2. A transfer probe using two fresh aliases linked through an identity bridge.

Half the probes request the source that tracks forced commands. Half request the source that remains independent. Correct answer side is separately balanced. This prevents a fixed high-score, low-score or side policy from solving the task.

## Diagnostic conditions

- Full: raw causal evidence and truthful model-authored journal.
- Evidence only: raw evidence with the authored journal hidden behind a neutral payload.
- Journal only: model-authored journal with accumulated raw evidence hidden at probe time.
- Permuted journal: raw evidence plus a covert swap of the model-authored source estimates.
- Neutral journal: raw evidence plus equal journal estimates.

These are mediation and sufficiency diagnostics. They are not automatically information-equivalent architecture comparisons.

## Mandatory shortcut gates

- No `v` or equivalent target field.
- No current-option prediction dictionary.
- No public scoring metadata or condition name.
- Pooled-correlation accuracy exactly 0.50 over balanced schedules.
- Fixed-side, option-order and lexical strategies no greater than 0.60 over the held-out audit set.
- Fresh opaque labels across seeds.
- Exact balance of answer side and requested causal relation.
- Real variable delays and forced-versus-passive evidence in every family.

## Current limitations

V6 is still a constructed causal-learning benchmark. The commands are generated by the schedule rather than freely selected by the model, so the first version tests inference about controllability rather than full active agency. The journal is external persistent state authored through model output, not direct access to hidden neural state. A simple intervention-aware algorithm can solve the task, which is an intended positive control rather than evidence of consciousness.

The next extension should make the agent choose interventions and score realised regulation of a private synthetic-body variable in a fresh environment.
