# Stage 1 manuscript outline

Status: internal draft for external criticism. No target-model v4 data have been collected.

## Working title

Information equivalence and causal architecture in synthetic consciousness indicator tests

## Central claim

Project Theta tests whether persistent artificial-agent mechanisms produce specified
behavioural and computational indicators under controlled interventions. No outcome in this
programme establishes phenomenal consciousness.

## Motivation

Earlier development studies confounded a specialised self-model with access to a
wrapper-computed ownership table. They also exposed a probe identifier correlated with the
correct answer side. The corrected programme therefore separates three questions:

1. Can public task metadata solve the probe without the intended information?
2. Does correct binding content, rather than context shape, explain performance?
3. Does a causal architectural mechanism support transfer that an information-matched generic
   mechanism does not?

V4 answers the first two questions. It is not a causal architecture experiment because the
full and generic-table conditions produce byte-identical model inputs. Their behavioural
distributions should therefore be equivalent apart from provider sampling and routing noise.

## V4 methods audit

- Four conditions: full, generic table, misattributed table and permuted table.
- Twelve independent cue families per run.
- Forty-eight protocol-defined acquisitions and twelve scored probes.
- Inference only on probes.
- Hidden answer sides generated by a separately seeded balanced shuffle.
- Public identifiers, condition, seed, ownership labels and scoring keys withheld.
- Full and generic-table contexts compared byte for byte before target execution.
- Metadata rules fitted on one seed set and evaluated on a disjoint seed set.

### V4 estimands

The full versus generic contrast is an equivalence and infrastructure check, not evidence for a
self-model effect. The wrong-content contrasts test whether correct associations are used.
Seed-level accuracy is the primary summary. Probe-level observations are nested within seeds.

### V4 interpretation

- Full approximately equals generic: consistent with the information-access explanation of v3.
- Truthful conditions outperform wrong-content controls: the model uses supplied bindings.
- Full differs materially from byte-identical generic: inspect routing, stochastic sampling,
  hidden state and implementation errors before any psychological interpretation.

## Next causal study

The next protocol must manipulate an internal update mechanism while matching observations,
memory capacity, serialized interface, inference budget and scoring opportunity. Its critical
outcomes must be held-out transfer or intervention effects that cannot be solved by retrieving a
supplied ownership table.

## Statistical plan still requiring external review

- Define the smallest effect or equivalence margin worth interpreting.
- Estimate run-level variance in a development model that will not be used for confirmation.
- Simulate power with seeds and repeated model invocations as separate variance components.
- Freeze exclusions, retry handling and multiplicity treatment before target collection.
- Use an exact versioned provider model or a reproducible open-weight runtime for confirmation.

## Reporting boundary

Report behavioural outcomes, implemented state transitions and causal intervention effects
separately. Do not infer feeling, sentience, pain, subjective experience or moral status from
task performance.
