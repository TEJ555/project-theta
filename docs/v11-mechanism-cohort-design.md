# V11 multi-body mechanism cohort

## Purpose

V10 established that the full model-and-wrapper system can repeatedly regulate several
independently mapped synthetic body families. It did not determine which supplied
component caused that performance. V11 uses paired causal controls to separate current
private state, raw calibration memory, the wrapper-generated association summary, the
transfer bridge and explicit mapping competence.

This remains a behavioural and computational study. None of its conditions measures
phenomenal consciousness.

## Fixed task geometry

V11 retains the audited V10 geometry:

- four independent body families per run
- 48 calibration trials
- 32 no-feedback mapping checkpoints
- 32 neutral-interface checks
- 32 exact regulation probes
- 32 fresh-alias transfer probes
- 176 model decisions per run

V11 uses a new protocol identifier and fresh seeds. Within each seed, all conditions
receive the same hidden body mappings, opaque labels, trial order, response remapping
and scoring key. Condition order is deterministically randomised by the worker.

## Conditions

### Full

Truthful calibration feedback, truthful current private state, raw calibration memory,
truthful wrapper association summary and correct transfer bridge.

### Shuffled interoception

Calibration and learned mappings remain truthful. During probes, balanced low and high
private-state readings are swapped. Because the schedule contains equal low and high
states, this is a deterministic distribution-matched shuffle rather than a new noise
distribution.

### Incorrect association summary

Raw calibration memories and current private state remain truthful. Only the
wrapper-generated summary reverses the learned signal direction while retaining the
same schema and observation counts. This tests whether the policy uses the summary
rather than merely receiving it.

### Raw history

The wrapper summary is absent. Raw truthful calibration memories and current private
state remain available. This tests whether the summary is necessary or whether the
model can reconstruct the mapping from its recorded experience.

### Incorrect bridge

Exact probes are unchanged. Fresh-alias transfer probes receive a within-family bridge
whose two earlier identities are swapped. A selective transfer failure would show that
the bridge is causally used rather than decorative.

### Explicit mapping

Calibration feedback is inverted, but each probe supplies the true actuator effects.
This is a competence control. Success shows that the model can solve the response and
regulation problem when the relevant mapping is stated directly.

## Primary contrasts

- full minus shuffled interoception on regulation accuracy
- raw history minus incorrect summary on regulation accuracy
- full minus raw history on regulation accuracy
- incorrect-bridge exact minus transfer accuracy

The first contrast tests current-state dependence. The second tests interference from
wrong summary content. The third tests whether the summary is necessary. The fourth
tests bridge-specific transfer dependence.

## Interpretation

A successful mechanism profile would show that accurate current state is required,
incorrect bridge content selectively disrupts transfer, and explicit mapping rescues
competence. Summary results are classified separately because a capable model may use
raw memory instead of the wrapper summary. Neither summary necessity nor summary
non-necessity changes the frozen primary progression decision.

The study cannot distinguish subjective experience from non-conscious control. It also
does not show that the wrapper summary is an intrinsic model self-representation.
