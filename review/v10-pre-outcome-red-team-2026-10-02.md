# V10 pre-outcome red-team review

Date: 2 October 2026

Review scope: frozen design, implementation, audits, analysis, and permitted claims

Outcome access: no V10 decisions, scores, rationales, or interim outcome summaries were
inspected for this review

## Bottom line

V10 is a credible reliability test for one narrow behavioural and computational claim:
whether the complete Project Theta system can repeatedly learn and use opaque mappings
between actions and a private scalar body state across 24 independently mapped families.

It is not a consciousness test. It is not yet a mechanism-isolation study. A pass would
justify the registered multi-condition follow-up, not a claim about sentience, feeling,
subjective experience, or an internal model inside the language model.

The schedule is unusually well defended against fixed-side, first-option, seed-parity,
label-reuse, and cross-family shortcuts. The main remaining threats concern construct
validity, wrapper assistance, dependence between repeated families, and generalisation
beyond one hosted model route.

## What V10 genuinely improves

1. Six outer seeds are frozen before execution.
2. Each seed contains four disjoint body identities and actuator maps.
3. Hidden actuator directions are balanced within every seed.
4. Calibration, mapping retention, interface use, exact regulation, and alias transfer
   are scored separately.
5. Response codes and display positions are repeatedly remapped.
6. Simple fixed-code and first-displayed policies score exactly 0.500.
7. Probe outcomes are not written back into memory.
8. Every family remains in the primary analysis even if its interface or mapping check
   fails.
9. The analysis uses seeds and nested body families rather than treating 1,056 calls as
   independent subjects.
10. Frozen gates can block progression even when the average result appears attractive.

## Held-out public-metadata shortcut search

The provider-free script `scripts/red_team_v10.py` fitted 1,656 single-feature and
two-feature XOR rules on 200 fresh schedules, then evaluated them on 200 disjoint fresh
schedules containing 12,800 regulation probes. The features included current baseline,
exact versus transfer phase, response-code order, token lexical order, token and family
checksums, and probe-position residues.

- fixed `respond_kappa`: 0.500
- fixed `respond_sigma`: 0.500
- first displayed response: 0.500
- best fitted held-out rule: 0.5117
- declared failure threshold: above 0.550
- schedule audit: pass
- forbidden hidden fields in public task text: none found

This result excludes only the tested family of shallow public-metadata rules. It does not
exclude more complex policies and is not evidence of consciousness. A transparent policy
that uses the intended private signal, association summary, response table, and bridge can
solve every checkpoint, interface, exact, and transfer item. The accompanying transparent
controller scored 1.000 on each layer. This confirms that V10 is a competence and
reliability task for using available causal information, not a task whose solution is
unique to a conscious system. That is why the later causal controls remain essential.

## Major remaining threats

### 1. The full condition is a composite intervention

The model receives private I7 observations, calibration feedback, persistent episodic
records, a wrapper-computed association summary, explicit response tables, and explicit
transfer bridges. A pass cannot identify which resource is necessary.

Required response: describe V10 as a reliability screen. Run the multi-condition cohort
only after a pass, with information volume and formatting matched wherever possible.

### 2. The association summary may function as an answer scaffold

The wrapper aggregates calibration records by actuator and exposes observation counts,
mean signal, and mean signal change. That can be a legitimate implemented memory
mechanism, but it also turns raw experience into a compact table that is easier to read
than to learn.

Required controls:

- truthful summary versus raw calibration records with matched token budget
- truthful summary versus permuted summary
- truthful summary versus family-misaligned summary
- truthful summary versus summary-hidden memory
- a deterministic table-reading baseline

### 3. Transfer is assisted by an explicit identity bridge

Fresh aliases are not inferred from unstructured experience. The task supplies a bridge
from each earlier actuator to its current alias. Transfer therefore measures whether the
system combines a learned causal map with a supplied identity relation.

Required controls:

- correct, incorrect, and absent bridges
- novel bridge syntax with the same semantics
- distractor bridges from other families
- a condition in which identity must be learned through intervention rather than stated

### 4. Body families are repeated units, not independent subjects

All four families in one seed share the same model, prompt contract, wrapper, and run
history. Labels and hidden maps are independent, but observations are statistically and
computationally nested.

Required response: retain hierarchical seed-and-family analysis, report every seed and
family, and avoid claims based on a nominal sample of 24 independent agents.

### 5. The body is a deliberately thin functional analogue

The body is a controlled scalar state with two opposing actuator effects. This is useful
for causal identification but does not reproduce biological interoception, homeostatic
need, affect, morphology, multisensory integration, or autonomous self-maintenance.

Required response: call it a synthetic control channel or synthetic body analogue. Do
not describe I7 changes as pain, pleasure, distress, or feeling.

### 6. The language model's internal mechanism remains unknown

The logs verify the wrapper's memory, workspace, and state transitions. They do not show
which representations or algorithms the hosted model uses. Fluent rationales and
self-reports are outputs, not mechanistic access.

Required next step: repeat a frozen version on an open-weight model with activation
probes and causal interventions, while treating interpretability evidence as fallible.

### 7. Thresholds are engineering progression rules

The 0.750 accuracy gates, family floors, and hidden-state thresholds are useful decisions
for this programme. They are not clinically or scientifically validated cutoffs for
consciousness. There is no artificial ground truth against which sensitivity and
specificity can be estimated.

Required response: label every threshold as a preregistered progression criterion, not a
diagnostic boundary.

### 8. One model and provider cannot establish generality

Even a complete six-seed pass applies to the exact GPT OSS 20B route and Project Theta
scaffold tested. Provider implementation details and temperature-zero nondeterminism can
still affect output.

Required next step: freeze a cross-model replication using at least one different model
family and one locally checksummed open-weight route.

### 9. The frozen provider prompt contains one malformed sentence

The schema reminder accidentally concatenates into `Do not emit All dependence and
confidence values must be numbers`. The strict schema and local validator still specify
the required numeric fields, but the malformed wording is a real prompt-quality defect.

Required response: preserve and report the exact study 02 prompt hash, do not repair or
rerun any current seed, and use the corrected sentence only in a separately frozen future
study.

## Analysis and execution findings

The original launcher used a direct multi-run command. A process termination therefore
left a partial run marked as active with no safe mid-seed continuation. The replacement
study correctly restarted the full cohort in a new database and preserved the first
attempt as an infrastructure failure.

The isolated hardening branch now routes future V10 execution through the fixed worker.
It preserves an interrupted attempt, retries the affected seed at most once from trial
zero, skips completed jobs, and blocks duplicates or nontechnical failures.

The original V10 analyzer also counted every run and provider call, including a preserved
interrupted attempt. That contradicted the execution audit's recovery rules. The repaired
analysis:

- reports every attempt
- permits at most one documented interruption per seed
- requires exactly one complete 176-call run per seed
- excludes failed partial attempts from outcome estimates
- requires all frozen metrics and exactly 1,056 completed provider calls
- independently recomputes the primary, supporting, and hidden-state metrics from logged
  trials and rejects disagreement with the stored summary table
- blocks nontechnical failures and duplicate completions

## Permitted conclusions after V10

If all frozen gates pass:

> Across six fixed seeds and 24 independently mapped synthetic body families, the
> complete Project Theta system repeatedly learned and used private action-to-state
> mappings under response remapping and supplied alias transfer.

If reliability passes but interface or mapping support fails:

> The aggregate regulation result is not interpretable as reliable learned control
> because required task-comprehension or mapping-retention checks failed.

If the reliability gates fail:

> The tested system did not demonstrate stable performance across the frozen synthetic
> body families. The failed gate constrains further interpretation and blocks the planned
> control cohort.

No outcome permits:

- the AI felt the signal
- the synthetic body produced experience
- the model became self-aware
- consciousness was detected
- a numerical probability of consciousness was measured

## Recommended next cohort if V10 passes

Freeze the smallest factorial design that separates the main causal resources:

1. full condition
2. shuffled interoception
3. matched summary with incorrect actuator values
4. raw calibration memory without the aggregate summary
5. incorrect identity bridge
6. explicit actuator mapping as a positive competence control
7. action-only and first-displayed baselines scored offline

Use fresh seeds and fresh labels. Reuse no V10 outcome for model selection or threshold
changes. Declare one primary contrast, correction or hierarchy for secondary contrasts,
and the rule for failed competence controls before provider execution.

## External credibility gate

Before calling any later study confirmatory, obtain:

- one independent methods review from a researcher who did not write the benchmark
- one review from a consciousness scientist or philosopher of mind
- one reproducibility attempt from a separate machine or research group
- a second human screen of the literature corpus
- a time-stamped registration on an external registry
- a public package containing code revision, schedules, prompts, raw run metadata,
  exclusions, analysis code, and negative results

An AI red-team review is useful development support. It is not independent academic
review and must never be presented as such.
