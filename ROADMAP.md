# Roadmap

## v0.2 — completed locally

- guaranteed acquisition and blinded balanced forced-choice probes;
- held-out feature generalization and implicit route binding;
- delayed sequence outcomes and causal architecture ablations;
- paired analysis, bootstrap intervals and validity warnings;
- schema 2 hashes, API metadata, checkpoints and recovery;
- locked bounded worker plus Docker/systemd deployment examples;
- 20-seed, 340-run scripted validation.

## API pilot gate

- preregister a small target-model pilot;
- run one model and three private-theta conditions with explicit run/call budgets;
- audit every adapter context for leakage and every provider response for validity;
- compare at least one model snapshot with a recorded fake-adapter integration test;
- review tokens, latency, provider cost, stop requests and failed calls;
- require independent welfare/method review before continuous execution.

## v0.3 — mechanistic and external validation

- matched token/context padding under architecture ablation;
- alias/mapping/delay reversal and adversarial shortcut suites;
- open-weight activation and causal mediation hooks;
- non-language and simpler associative baselines;
- cross-model measurement invariance, power simulations and external replication;
- blinded export/analysis package with a frozen public protocol.

No milestone converts functional indicators into proof of phenomenal consciousness.
