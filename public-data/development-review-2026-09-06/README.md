# Development evidence bundle

This reviewed export contains the completed self-model binding v3 confirmation tranche one and temporal-binding v2 replication records used in the 6 September methods review.

It includes per-run configurations, artifact hashes, metrics, scored probe inputs and responses, and preserved failure status. It excludes provider session identifiers, raw provider metadata, API credentials and working SQLite files. Run identifiers are replaced with one-way pseudonyms.

These records are published for reproducibility and criticism. Both studies are classified as development evidence because their schedules admit a public answer-position shortcut. They are not confirmatory evidence and they do not support an inference about phenomenal consciousness.
